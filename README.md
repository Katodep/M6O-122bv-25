## Реализованная функциональность

### Класс StudentTable (src/db/backend/memory.py)
- `create_record()` - добавление записи с валидацией
- `select_record()` - чтение с фильтрацией по любым полям
- `update_record()` - обновление существующей записи
- `delete_record()` - удаление записи по ID

### Класс StudentTUI (src/db/tui.py)
- Текстовый интерфейс с меню
- Обработка ошибок ввода
- Взаимодействие с пользователем

### Обработка ошибок
- `InvalidAgeError` - отрицательный возраст
- `DuplicateIDError` - дублирование ID
- `KeyError` - запись не найдена

### Сортировка записей
- Поддерживаемые поля: student_id, first_name, second_name, age, sex
- Порядок сортировки: по возрастанию или убыванию
- Исходный порядок записей в таблице не изменяется
- При пустой таблице возвращается пустой список
### Три режима работы базы данных
1. **In-memory** - данные хранятся в оперативной памяти (не сохраняются)
2. **File (JSON)** - данные сохраняются в JSON файлы
3. **File (CSV)** - данные сохраняются в CSV файлы

### Класс Table (src/db/backend/table.py)
- Управление структурой таблицы
- Валидация полей при вставке
- Фильтрация записей

### Классы Database (src/db/backend/)
- `MemoryDatabase` - in-memory реализация
- `JSONDatabase` - файловая реализация (JSON)
- `CSVDatabase` - файловая реализация (CSV)

### Класс StudentTUI (src/db/tui.py)
- Текстовый интерфейс с меню
- Выбор типа базы данных при запуске
- Обработка ошибок ввода
- Взаимодействие с пользователем
