## Реализованная функциональность

### База данных (in-memory)
- Хранение записей в оперативной памяти (список кортежей)
- Предметная область: **Студенты**

### Поддерживаемые операции

#### 1. Добавление записи (`create_record`)
- Валидация возраста (не может быть отрицательным)
- Проверка уникальности ID
- Автоматическое удаление лишних пробелов

#### 2. Чтение записей (`select_record`)
- Фильтрация по одному или нескольким полям
- Возможность фильтрации по: ID, имени, фамилии, возрасту, полу
- Возврат копии данных (защита от внешнего изменения)

### Обработка ошибок
- `InvalidAgeError` - при отрицательном возрасте
- `DuplicateIDError` - при попытке добавить существующий ID
- `KeyError` - при обновлении/удалении несуществующей записи

### Консольный интерфейс (TUI)
Текстовый интерфейс с меню для взаимодействия с пользователем:
1. Добавить запись
2. Показать все записи
3. Найти записи по фильтру
4. Удалить по id
0. Выход
